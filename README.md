# Cloud Development Environment – Project

This project is a cloud-based development environment using **GitHub Codespaces**.

## 🚀 How to open the project in Codespaces
1. Go to this repository.
2. Click the green **Code** button.
3. Select **Open with Codespaces** → **New Codespace**.
4. The environment will open as a full VS Code in the browser.

## 🧪 Running Python files
If you have Python files (like helper.py), run them using:

```bash
python helper.py
